# Hugo site for Cloudflare Pages

This directory contains the Hugo version of the personal site.

Cloudflare Pages settings:

- Framework preset: Hugo
- Build command: `hugo --gc --minify`
- Build output directory: `public`
- Root directory: `hugo-site`
- Recommended environment variable: `HUGO_VERSION=0.158.0` or newer

No deployment has been run from this migration.
