## Variant: Portfolio Command Center

### Design stance
A Stripe-inspired authority dashboard for a multi-product founder.

### Key choices
- Layout: Hero + founder dashboard + product/thesis map.
- Typography: Light Source Sans 3, Source Code Pro for labels.
- Color: White, deep navy, purple CTA, blue-tinted shadows.
- Interaction: CTA toast states.

### Trade-offs
- Strong at: business credibility, product portfolio clarity, investor/customer scanning.
- Weak at: less personal and less intimate than the editorial direction.

### Best for
- Customers, partners, investors, and anyone evaluating your credibility quickly.
