## Variant: Founder OS Dark

### Design stance
A Linear-inspired dark operating-system page for a technical founder building with AI agents.

### Key choices
- Layout: Hero plus live-looking portfolio console.
- Typography: Precise Inter + JetBrains Mono.
- Color: Near-black, muted grays, one violet accent.
- Interaction: CTA toast states.

### Trade-offs
- Strong at: technical authority, AI-builder credibility, premium devtool feel.
- Weak at: warmth and approachability for non-technical visitors.

### Best for
- Founder peers, AI/devtool readers, technical customers, people who should feel “this person ships.”
